# 设计文档（Design Docs）

FleetView 的设计文档存放目录。每份文档在实现之前先写，实现之后保留为历史记录 —— 因此文档不删、不覆盖，只追加新版本。

## 命名约定

```
YYYY-MM-DD-<主题>.md
```

日期是**文档创建日期**（不是最后修改日期），保证 `ls` 天然按时间排序。同一主题的重大改版另起一份新文档，并在旧文档顶部标注 `已被 <新文档> 取代`。

## 文档头

每份文档开头必须有一个元信息表，至少包含：

| 字段 | 说明 |
|---|---|
| 文档类型 | 设计文档 / 调研 / 决策记录 |
| 创建日期 | `YYYY-MM-DD` |
| 最后更新 | `YYYY-MM-DD` |
| 状态 | 草案 / 已确认 / 实现中 / 已实现 / 已废弃 |
| 对应代码版本 | 写作时的 git commit（便于日后判断文中行号是否还有效） |
| 待决事项 | 指向文末需要拍板的开放问题 |
